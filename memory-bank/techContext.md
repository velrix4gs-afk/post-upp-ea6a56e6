# Tech Context

## Technologies Used

1. React for the frontend.
2. TypeScript for type safety.
3. Vite for fast development and building.
4. Tailwind CSS for styling.
5. Supabase for backend services including Postgres, Auth, RLS, Edge Functions, Storage, Realtime, and `pg_net`.
6. Firebase Cloud Messaging for push notifications.
7. Stream Video SDK for voice/video calls.
8. Capacitor for mobile development targeting Android.
9. Vercel for deployment.

## Development Setup

1. Node.js and npm or bun installed.
2. Supabase account and project set up.
3. Firebase account and project set up.
4. IDE for code editing and debugging.

## Constraints

1. The application must be built using React, TypeScript, Vite, and Tailwind CSS.
2. User authentication and data storage must be implemented using Supabase.
3. The application must be deployed using Vercel.
