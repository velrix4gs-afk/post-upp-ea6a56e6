# General Rules
- Always write clean, modular, and well-commented code.
- Never delete or overwrite existing code unless explicitly instructed to do so.
- Do not use placeholder comments like `// ... rest of code`. Always write the complete file.
- If a file gets too long (over 300 lines), suggest splitting it into smaller files.
- Always explain your plan before making significant changes to multiple files.

# Tech Stack & Style (EDIT THIS TO MATCH YOUR PROJECT)
- Frontend: React (or Next.js), Tailwind CSS.
- Backend: Node.js, Express.
- Language: TypeScript (Strict mode). Never use `any`.
- Styling: Use standard Tailwind classes. Do not write custom CSS files.
- State Management: Zustand.

# Tool Usage
- Always read the existing files before trying to edit them.
- When running terminal commands, use standard package managers (npm/pnpm).
