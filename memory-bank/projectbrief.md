# Project Brief

## Overview

POST UP (POST-UPP) is a social app that includes features such as a feed, stories ("Showcases"), real-time messaging, voice/video calls, and push notifications. The project was originally built in Lovable and is now being hand-edited directly in the repository.

## Objectives

1. Finish out core social features (composer, chat media, voice notes).
2. Polish the UI with a set of custom animated components ("flair" components).
3. Ensure the application is responsive and works well on all devices.

## Constraints

1. The application must be built using React, TypeScript, Vite, and Tailwind CSS.
2. User authentication and data storage must be implemented using Supabase.
3. The application must be deployed using Vercel.
